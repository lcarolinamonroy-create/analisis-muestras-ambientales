# Evaluación del cumplimiento ambiental de una PTAR en una empresa láctea

## Descripción del proyecto

Este proyecto analiza resultados fisicoquímicos de muestras de agua residual provenientes de una planta de tratamiento de aguas residuales (PTAR) de una empresa dedicada a la producción de productos derivados de la leche.

El objetivo es revisar el cumplimiento de parámetros de referencia para el vertimiento de aguas residuales y evaluar la efectividad del tratamiento realizado por la PTAR.

Los datos utilizados son simulados y tienen fines educativos.

## Parámetros analizados

- pH
- DBO5
- DQO
- Sólidos suspendidos totales (SST)
- Grasas y aceites

## Preguntas de análisis

- ¿Qué parámetros cumplen con los límites de referencia?
- ¿Qué parámetros presentan incumplimientos?
- ¿La calidad del agua mejora entre la entrada y la salida de la PTAR?
- ¿El sistema de tratamiento está siendo efectivo?
- ¿Qué parámetros incumplen con mayor frecuencia?
- ¿Qué posibles fallas del sistema podrían relacionarse con los incumplimientos?
- ¿En qué fechas se presentan mayores problemas?

## Herramientas utilizadas

- SQL
- GitHub
- Archivos CSV

## Estructura del proyecto

- `datos_muestras.csv`: datos simulados de los análisis de laboratorio.
- `consultas.sql`: consultas utilizadas para analizar los resultados.
- `README.md`: descripción, objetivos y preguntas del proyecto.

## Nota técnica

Los datos son simulados y los límites utilizados son referencias educativas. Para una evaluación real se deberían verificar la normativa vigente, el tipo de vertimiento, el permiso ambiental y los criterios establecidos por la autoridad ambiental competente.
